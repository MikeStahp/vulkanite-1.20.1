## 2024-05-24 - Avoid Java Streams in Performance-Critical Rendering Hot Paths
**Learning:** In the Vulkanite codebase, hot rendering paths like `VulkanPipeline.renderPostShadows`, `VCmdBuff.bindDSet`, and `CommandManager.Queue.waitForExecutions` execute hundreds or thousands of times per frame. Using Java Streams (e.g., `.stream().mapToInt()`, `.stream().map().toList()`, `Arrays.stream()`) in these locations causes immense GC pressure due to hidden per-frame object allocations (iterators, lambdas, stream wrappers, boxing/unboxing overhead, and per-frame `ArrayList` instantiations).
**Action:** Always replace Java Streams with traditional `for` loops, direct array manipulation, and reusable collections when optimizing critical rendering or command-encoding loops in this codebase.
