## 2026-04-20 - Java Stream API overhead in Vulkanite hot paths
**Learning:** In Minecraft engine/rendering pipelines (like Vulkanite), using Java 8's Stream API inside hot rendering loops or command buffer generation paths (e.g., `VulkanPipeline.renderPostShadows`, `CommandManager`) generates significant GC pressure from temporary object allocations (lambdas, iterators, Stream instances) which can introduce stutter. Additionally, relying on `stream().max()` with an empty collection or lower incoming value inadvertently breaks timeline semaphore wait values because it fails to strictly monotonically increase.
**Action:** Always replace `.stream()` and lambda functional calls with standard `for` loops in performance-critical paths. Use raw loops and explicit array/list instantiations instead to ensure zero-allocation operations per frame and prevent timeline regression bugs.
