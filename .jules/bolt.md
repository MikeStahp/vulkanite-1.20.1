## 2024-06-25 - Replace Java Streams in Hot Paths
**Learning:** This codebase (Vulkanite) leverages Vulkan and raytracing in a performance-critical loop that executes per-frame. Using standard Java Streams (like `.stream().mapToInt()`, `.stream().map(...).toList()`) in hot rendering paths (e.g., `VulkanPipeline.renderPostShadows`, `VCmdBuff.bindDSet`, etc.) acts as a massive anti-pattern. These operations create excessive per-frame garbage (iterators, lambdas, boxed primitives) that leads to Garbage Collector pressure and stutters in frame times.
**Action:** When iterating over collections in hot paths, explicitly pre-allocate target collections or arrays using the known size of the source collection (`new ArrayList<>(source.size())` or `new int[source.size()]`) and use traditional indexed loops. Replace `toList()` with `new ArrayList<>()` or standard explicit iterations to eliminate dynamic resizing and per-frame object allocation overheads.
