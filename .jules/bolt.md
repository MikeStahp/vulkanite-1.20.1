## 2024-06-25 - Replace Java Streams in Hot Rendering Paths
**Learning:** Hot paths in Vulkanite like `VulkanPipeline.renderPostShadows`, `VCmdBuff.bindDSet`, and `CommandManager.Queue.waitForExecutions` are highly sensitive to object allocation and Garbage Collection (GC) pressure. Standard Java Streams (`.stream().mapToInt()`, `.stream().map().toList()`, `.max()`) inherently create multiple intermediate objects and introduce boxing/unboxing overhead, slowing down the per-frame performance.
**Action:** Always replace Java Streams with traditional loops (`for`), pre-allocated arrays, or sized `ArrayList`s when refactoring rendering hot loops or performance critical functions. Be careful with mutating or copying collections, making sure `ensureCapacity` is used when adding heavily to lists.
