## 2024-03-24 - Elimination of GC Pressure in Vulkan Rendering Hot Paths
**Learning:** In Minecraft rendering contexts with Vulkanite, hot paths executing every frame (`VulkanPipeline.renderPostShadows`, `VCmdBuff.bindDSet`, `CommandManager.Queue.waitForExecutions`) heavily penalize the use of Java Streams (`.stream().mapToInt()`, `.stream().max()`, etc.). The object allocations for streams, lambdas, and boxing create significant GC pressure, leading to frame stutters.
**Action:** When working in these codebase-specific high-frequency loops, strictly avoid Java Streams. Prefer simple enhanced `for` loops, manual array allocations initialized to the exact size of the collection, and `Arrays.fill()` for constant assignments. Use `ArrayList<?>` pattern matching to access `.ensureCapacity()` safely.
